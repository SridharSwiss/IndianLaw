## Standards — Informational

### OBL-STD-01 — IS 17428 / ISO 27001 certification
- **requirement:** IS 17428 is the Indian National Standard for Information Security Management Systems (ISMS), aligned with ISO/IEC 27001. SPDI Rules 2011 r.8 requires body corporates to follow "reasonable security practices" per a documented standard. IS 17428 / ISO 27001 certification is the recognized baseline.
- **not-auto-verifiable:** true
- **severity:** low
- **first-action:** Conduct a gap analysis against ISO 27001 Annex A controls. Engage a NABCB-accredited certification body. Estimated timeline: 6–12 months for first certification.
- **citation:** SPDI Rules 2011 r.8; DPDP Act 2023 §8(1)

### OBL-STD-02 — IS 17802 — Accessibility standard for web
- **requirement:** IS 17802:2018 is the Indian standard for web accessibility, based on WCAG 2.1. Mandatory for government and SEBI-regulated entities; recommended for all.
- **not-auto-verifiable:** false
- **severity:** low
- **evidence_hints:** See accessibility.md for code-checkable obligations. This standard item is informational — publish an accessibility statement declaring IS 17802 / WCAG 2.1 AA conformance.
- **first-action:** Run automated accessibility scan (axe, WAVE, Lighthouse). Fix critical issues. Publish accessibility statement.
- **citation:** IS 17802:2018; RPwD Act 2016 §40
